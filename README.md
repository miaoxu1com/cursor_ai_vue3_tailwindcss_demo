# 文件上传组件示例

这是一个使用Vue 3、Tailwind CSS和shadcn风格实现的文件上传组件示例。

## 功能特点
- 支持拖拽上传
- 支持点击上传
- 文件类型限制为jpg/png
- 文件大小限制为500kb
- 上传区域视觉反馈
- 错误提示

## 技术栈
- Vue 3
- Tailwind CSS
- shadcn UI风格

## 使用方法
1. 将FileUpload组件导入到您的项目中
2. 在template中使用组件 
3. 使用npm run dev 运行前端项目
4. 后端代码和前端代码各自独立一个文件夹相互隔离
5. 前端代码只放在前端后缀结尾的文件中.vue
6. 后端代码只放在后端结尾的文件中如.py
7. 后端渲染因为数据是动态的需要从后端获取需要动态生成
